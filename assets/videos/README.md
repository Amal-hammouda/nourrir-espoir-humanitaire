Emplacement de la vidéo
======================

Ajoutez ici un fichier vidéo dont l’association détient les droits, par exemple `presentation.mp4` (H.264), puis renseignez `src: "assets/videos/presentation.mp4"` dans `assets/site-config.js`.

Le lecteur HTML5 s’activera sans lecture automatique, avec commandes, lecture intégrée sur mobile (`playsinline`) et chargement différé (`preload="none"`). Le poster actuel est une photo d’illustration de stock ; remplacez-le par une image autorisée tirée de la vidéo lorsque le fichier sera disponible. N’utilisez pas de musique ou de séquences tierces sans autorisation.
